### 3.3 锂电池说明

TP4056 二合一保护功能：
- **过充保护**：电池电压到 4.2V 自动停止充电
- **过放保护**：电池电压低于 3.0V 自动切断输出
- **短路保护**：检测到短路自动断开

602535 600mAh + TP4056 二合一 = 安全的电池供电方案。

### 3.4 MS4030 vs INMP441

MS4030 是 INMP441 的兼容型号，国产替代，价格更低（¥6.2 vs ¥7-8），I2S 接口完全兼容。实际使用中没有差别，可以直接替换，不需要改代码。

## 7. 关于电工电表

**需要买，推荐买。**

万用表是硬件调试最基础的工具，TinyPal 项目里可以用它：

| 使用场景 | 万用表操作 |
|---------|-----------|
| 确认 TP4056 OUT 有 5V 输出 | 直流电压档，红笔接 OUT+，黑笔接 GND |
| 确认 ESP32 3.3V 引脚有电 | 直流电压档测 3.3V 引脚 |
| 检查接线是否接通 | 通断档（蜂鸣档），两根表笔点接线两头，听是否响 |
| 排查喇叭没声音 | 测 MAX98357 输入 VIN 是否有 5V，测 SPK+/- 是否有输出 |
| 检查杜邦线是否断了 | 通断档测杜邦线两头，不响说明断了 |

**不需要买电烙铁**：
- 套餐配件都选了"焊好针"版本，到手直接插杜邦线，不需要焊接
- 只有极端情况下（比如杜邦线接触不良需要补锡）才需要电烙铁
- 先把项目跑通，以后再买电烙铁也不迟

**推荐入门配置**：万用表 + 镊子，足够 TinyPal 开发调试使用。
