## 1. 现状

当前典型接法：

- MAX98357 从 **ESP32 板载 5V** 取电
- I2S 数字音频（DIN / BCLK / LRC）由 ESP32 输出
- 喇叭为 **4Ω / 3W** 左右的小型裸喇叭

共用电源的好处：ESP32 与功放共地，**地环路 50Hz 嗡嗡声**通常不是主因。  
仍常见的问题：滋滋底噪、大音量破音、人声撕裂/浑浊、细碎嘶嘶声。

噪音来源大致排序：

1. ESP32 板载电源带不动喇叭峰值电流 → 供电电压抖动  
2. MAX98357 无输出滤波 → PWM 高频载波被听见  
3. 增益偏大 → 噪声一并放大  
4. 裸喇叭无腔体 → 声学清晰度差  

---

## 2. 噪音成因

### 2.1 供电能力不足 + 数字电流扰动（最主要）

ESP32 开发板的 `5V` 多来自 USB / 板载 LDO，可持续电流通常只有约 **0.5A～1A**。  
4Ω 喇叭在 5V 下峰值电流理论上可到约 **2.5A**，远超板载电源余量。

WiFi / CPU 瞬时电流也会在电源线上制造纹波。D 类功放会把电源上的杂波一起放大，表现为：

- 持续滋滋底噪  
- 大音量破音  
- 人声浑浊、撕裂  

### 2.2 MAX98357 无输出 LC 滤波（细碎嘶嘶）

芯片输出接近几百 kHz 的开关 PWM，不是平滑模拟波形。小喇叭电感量小，滤不掉超高频谐波，人耳会听到细碎白噪。这是芯片架构特性，**只改共用电源解决不了**。

### 2.3 增益设置不当

GAIN 悬空时增益约 **9dB**（见下节）。增益越大，电源噪声与 I2S 微小干扰越容易被放大，小音量下底噪更刺耳。

### 2.4 裸喇叭无密闭腔体

振膜前后声波抵消、低频缺失，细微机械振动杂音更明显，听感干瘪、清晰度差。

## 3. GAIN 是什么、为什么要改

### 3.1 作用是什么

`GAIN` 是 MAX98357 上的**硬件增益选择脚**，不是音量旋钮，也不是开关。

芯片把 I2S 数字音频转成喇叭驱动电流时，会按一个固定放大倍数工作。你**怎么接 GAIN**，就决定了这个固定倍数是多少（约 6 / 9 / 12 / 15dB）。接线一旦焊好/插好，整机运行期间增益不变；日常「大声一点 / 小声一点」应靠软件数字音量，而不是反复改 GAIN。

简单类比：GAIN 像功放上的「档位开关」（几档固定放大），软件音量像播客 App 里的音量条。档位太大时，背景沙沙声也会一起被放大。

### 3.2 为什么推荐接 5V（约 6dB）

| 目标 | 说明 |
|------|------|
| 降低底噪 | 增益从悬空约 9dB 降到约 6dB，电源纹波、线路干扰被放大得更少，小音量时滋滋声更轻 |
| 提高信噪比 | 人声/TTS 信号用软件把数字电平抬高；噪声在硬件侧已少放大一层，整体更干净 |
| 零成本立刻见效 | 只需一根杜邦线，不用焊电容、不用独立电源 |

若接 5V 后觉得偏小：优先在固件/云端**提高数字音量**（并预留约 10%～15% 防削波），不要为了响而把 GAIN 接到 GND（15dB）——那会把底噪一并拉大。

### 3.3 接法对照表

按 MAX98357 数据手册（模块丝印以实际为准）：

| GAIN 接法 | 约增益 | 本项目建议 |
|-----------|--------|------------|
| 接 VIN（5V） | **6dB** | **推荐默认**（底噪更低，响度用数字音量补） |
| 悬空 | **9dB** | 旧默认；能出声但底噪往往更大 |
| 经 100kΩ 接 GND | **12dB** | 一般不推荐对话场景 |
| 直接接 GND | **15dB** | 最大增益，底噪通常最明显 |

> 说明：部分网络资料写「悬空 = 12dB」，与手册不符。本文以手册为准：**悬空 ≈ 9dB，接 VIN ≈ 6dB**。

## 4. 升级步骤（层级 1→5）

按顺序做；每做完一层听一遍 TTS / 回放，再决定是否继续。

### 层级 1：零成本引脚配置（优先做）

**材料**：无（已有杜邦线即可）

**操作**：

```
MAX98357
  SD   → 5V（与 VIN 同电位，常使能）
  GAIN → 5V（约 6dB）
```

与搭建指南推荐默认一致。若你之前 GAIN 悬空，改成接 5V 即可。

**原理**：

- `SD` 悬空时芯片可能反复休眠/唤醒，产生噼啪、爆音；拉高后常开，消除启停噪声。  
- `GAIN → 5V`：把硬件增益降到约 6dB（见 [§3](#3-gain-是什么为什么要改)）；底噪更轻，响度不足时用软件数字音量补。

**验收**：

- [ ] 上电无明显噼啪爆音  
- [ ] 小音量底噪比 GAIN 悬空时更轻  
- [ ] 仍有声音（SD 必须为高）  

---

### 层级 2：电源去耦（抑制纹波、减轻破音）

**材料**：

- 0.1μF 陶瓷电容（104）×1  
- 10μF 电解电容（耐压 ≥10V）×1  
- （可选）10Ω 磁珠 ×1  

**操作**：

1. 断电。  
2. 在 MAX98357 模块背面，**紧贴 VIN 与 GND 焊盘**并联：
   - `0.1μF`：吸收高频尖峰  
   - `10μF`：平滑低频压降（电解正极接 VIN，负极接 GND）  
3. （可选）在 ESP32 `5V` 与功放 `VIN` 之间串入 10Ω 磁珠，再接到 VIN。

**原理**：电容把电源上的交流纹波旁路到地；喇叭瞬时大电流时电容短时放电，减轻电压骤降导致的失真。

**验收**：

- [ ] 大音量 TTS 破音减轻或消失  
- [ ] 滋滋底噪有所下降  

---

### 层级 3：独立 5V 供电 + 单点共地（根治供电瓶颈）

**材料**：

- 独立优质 **5V / ≥1A** 开关电源（或稳压模块）  
- 杜邦线：电源正 → 功放 VIN；电源负 → 功放 GND；**一根** GND 连 ESP32 GND  

**操作**：

1. **断开** MAX98357 `VIN` 与 ESP32 `5V` 的连接。  
2. 独立 5V 正极 → MAX98357 `VIN`。  
3. 独立 5V 负极 → MAX98357 `GND`。  
4. 用**一根**线连接：独立电源 GND（或功放 GND）↔ ESP32 GND（单点共地）。  
5. I2S 信号线（DIN / BCLK / LRC）与 `SD`/`GAIN` 仍按搭建指南接 ESP32；`SD`/`GAIN` 可继续接功放侧 5V（与 VIN 同电位）。

**注意**：

- 不要再让功放从 ESP32 `5V` 取电。  
- 必须共地，否则 I2S 参考电位漂移，可能无声或乱音。  
- 不要接成「两根电源地各自乱飞」形成大环路；共地用单点一根线即可。

**原理**：独立电源承担喇叭峰值电流；数字域（ESP32/WiFi）电流扰动不再串入功放供电回路。

**验收**：

- [ ] 大音量不再明显破音  
- [ ] 底噪显著低于「仅共用 ESP32 5V」时  

---

### 层级 4：消除 D 类 PWM 嘶嘶声

#### 方案 A（最简）：喇叭端 RC 吸收

**材料**：22Ω 电阻 ×1 + 0.1μF 电容 ×1  

**操作**：在喇叭两端并联一条支路：`22Ω` 与 `0.1μF` **串联**后再并到 SPK+ / SPK-。

```
SPK+ ──┬── 喇叭 ──┬── SPK-
       │          │
       └── 22Ω ── 0.1μF ──┘
```

**原理**：近似低通，截止频率约在人耳上限之上，削弱几百 kHz 开关载波，保留语音频段。

#### 方案 B：D 类专用 LC 滤波小板

电感 + 电容无源低通，滤波通常优于 RC；追求更干净音质时选用。

**验收**：

- [ ] 细碎嘶嘶 / 白噪明显减轻  
- [ ] 人声仍清晰，无明显闷糊（若过闷，检查 RC 数值是否过大）  

---

### 层级 5：密闭小腔体（听感清晰度）

**材料**：适合 4cm 喇叭的小木盒 / 塑料盒，或 3D 打印腔体；密封用海绵/热熔胶按需。

**操作**：

1. 喇叭振膜朝外固定在面板开孔上。  
2. 背面尽量密闭，减少前后声波短路。  
3. 避免振膜被硬物顶死。

**原理**：隔绝背面反向声波、补足低频、吸收部分机械振动杂音。

**验收**：

- [ ] 人声更饱满、不那么「干瘪」  
- [ ] 同等音量下清晰度更好

## 5. 软件（固件已实现）

当前 TinyBot 云端与固件约定为 **16kHz / 16bit PCM**（见 `tiny-bot-firmware/include/config.h`）。  
**不要**为了「音质」单独把喇叭改成 44.1kHz / 32bit，会与 TTS 采样率错位。

| 项 | 说明 |
|------|------|
| 保持 16kHz / 16bit | 与云端 hello / TTS 一致 |
| 数字音量 `TB_SPK_GAIN_Q8` | 默认 220（约 0.86，预留削波余量）；GAIN=6dB 后偏小可调到 256～320 |
| 空闲停 I2S 时钟 | 非播放时 `i2s_stop`，无 BCLK 时 MAX98357 休眠，减轻空载嘶嘶 |
| GAIN 硬件档 | 仍推荐 `GAIN → 5V`（约 6dB）；响度优先用数字音量，不要为了响把 GAIN 接 GND |

听感（底噪/响度）需上板确认；固件侧编译已覆盖上述宏与路径。

## 7. 总勾选清单

按优先级勾选：

- [ ] **L1** SD → 5V，GAIN → 5V（6dB）  
- [ ] **L2** VIN/GND 并联 0.1μF + 10μF（可选磁珠）  
- [ ] **L3** 独立 5V/≥1A + 单点共地，不再从 ESP32 5V 取电  
- [ ] **L4** 喇叭并联 RC（或 LC 滤波板）  
- [ ] **L5** 密闭小腔体  
- [ ] （可选）软件侧音量余量 / 空闲 mute（后续固件）  
- [ ] （可选）换带滤波的 I2S 功放板，或更大功率方案（见 [§8](#8-附录可选换模块)）  

做完 L1～L2 后若听感已可接受，可先停；L3 是供电问题的根治手段，对话场景优先考虑。换模块不是第一步——先把现有 MAX98357 按 L1～L5 做完，再决定要不要换板。

## 8. 附录：可选换模块

L1～L5 都是在**现有 MAX98357** 上优化。若做完仍不满意，或想要更大声，可以换板——但要分清「能直接换」和「不能直接换」。

### 8.1 优先：仍用 I2S，只换更好的板

| 方案 | 目的 | 固件 | 说明 |
|------|------|------|------|
| 换一块**带 LC / 输出滤波、去耦电容更全**的 MAX98357 模块 | 少焊电容、减轻 PWM 嘶嘶 | 基本不用改 | 引脚仍是 VIN/GND/DIN/BCLK/LRC/GAIN/SD，按搭建指南接线 |
| 换别的 **I2S 输入** 功放模块（需确认丝印与手册） | 更大功率或更好滤波 | 通常不用改采样率 | 必须仍是 I2S；核对 5V 供电、SD/GAIN 等价脚、喇叭阻抗 |

淘宝可搜：`MAX98357 滤波`、`MAX98357 LC`、`I2S 功放 带滤波`。

### 8.2 PAM8610：不能直接换，必须加 DAC

仓库对比文档提过用 **PAM8610（约 10W+10W / 常见标 5W～15W）**「替换」MAX98357。  
**结论先说清：拔掉 MAX98357、把 I2S 三根线插到 PAM8610 上 → 一定没声音，还可能误解接线。**

#### 为什么不能直接换

| 项目 | MAX98357（当前） | PAM8610（常见模块） |
|------|------------------|---------------------|
| 音频输入 | **I2S 数字**（DIN/BCLK/LRC） | **模拟线电平**（L_IN / R_IN / GND） |
| 供电 | 通常 **5V**（可接 ESP32 5V） | 通常 **7.5V～15V**（推荐 **12V / ≥2A**），**不要接 ESP32 5V 当主电源** |
| 喇叭输出 | SPK+ / SPK-（BTL） | L+/L-、R+/R-（立体声 BTL） |
| 固件 | 现有 I2S TX 即可 | 仍要 I2S，但中间多一块 **DAC** |

数据流必须变成：

```
ESP32 (I2S) ──► I2S DAC（如 PCM5102A）──► 模拟 L/R ──► PAM8610 ──► 喇叭
                     ▲
                     └── 取代原来的 MAX98357
```

#### 材料清单（在现有 ESP32 之外）

| 零件 | 规格 | 淘宝关键词示例 |
|------|------|----------------|
| I2S DAC | PCM5102A 模块（带排针） | `PCM5102A I2S DAC` |
| 功放 | PAM8610 模块（带电位器的常见） | `PAM8610 功放模块` |
| 电源 | **独立 12V / ≥2A**（或 9～12V 稳压） | `12V2A 开关电源` |
| 喇叭 | 4～8Ω，额定功率匹配（勿用过小纸盆硬推满功率） | 现有 4Ω/3W 可试听，大音量易破音 |
| 线 | 杜邦线 + 喇叭线；模拟音频线尽量短 | — |

> TinyBot 若只用电池 + TP4056，**一般没有 12V**。上 PAM8610 就等于另加一套较高压电源，体积和安全都要重新考虑。对话场景多数时候不如「MAX98357 + 独立 5V + 腔体」划算。

#### 接线（推荐：PCM5102A + PAM8610 单声道）

**1）卸下 MAX98357**  
断开 VIN/GND/DIN/BCLK/LRC/SD/GAIN 与喇叭。

**2）ESP32 → PCM5102A（I2S，引脚与原功放相同）**

| PCM5102A（常见丝印） | ESP32 | 说明 |
|----------------------|-------|------|
| VIN / VCC | 3.3V 或 5V（看模块标注） | 按模块说明书，多数支持 3.3～5V |
| GND | GND | 必须共地 |
| DIN / DATA | GPIO14 | 原 `I2S_SPK_DIN` |
| BCK / BCLK | GPIO26 | 原 `I2S_SPK_BCLK` |
| LCK / LRCK / WS | GPIO27 | 原 `I2S_SPK_LRCLK` |
| SCK / FMT 等 | 按模块默认（常悬空或板上跳线） | 以卖家说明为准；多数默认即可出声 |

固件：**先不改** `config.h` 里的 GPIO 与 16kHz；PCM5102A 一般能吃现有 I2S。若无声，再查模块是否要求 32bit / I2S 格式跳线（属进阶排查）。

**3）PCM5102A → PAM8610（模拟）**

| PCM5102A | PAM8610（常见丝印） | 说明 |
|----------|---------------------|------|
| LOUT / LOUT+ | L_IN（或 INL） | 左声道 |
| ROUT / ROUT+ | R_IN（或 INR） | 右声道；**单喇叭可只接左，右悬空或并接左** |
| GND | GND（音频地） | 与 ESP32 / DAC 共地 |
| — | — | 若 DAC 只有单端输出，接到模块的「信号」脚，地接 GND |

单喇叭时两种常见做法：

- **只用左声道**：喇叭接 PAM8610 的 `L+` / `L-`，`R_IN` 可悬空（部分模块建议经电容接模拟地，以板子说明为准）。  
- **左右并联输入**：DAC 的 L 与 R 短接后再进 `L_IN` 与 `R_IN`，喇叭仍只接一侧（或双喇叭立体声）。

**4）PAM8610 供电与喇叭**

| PAM8610 | 接到 | 注意 |
|---------|------|------|
| +V / VIN / DC+ | **独立 12V+** | 推荐 12V；电流 ≥2A；**禁止**把 12V 接到 ESP32 的 5V/3.3V |
| GND / DC- | 电源负极，并与 ESP32 GND **单点共地** | 共地一根线即可 |
| L+ / L- | 喇叭（单声道时用这一对） | **BTL 输出**：`L-` **不要**当系统地去接 ESP32 GND |
| R+ / R- | 第二只喇叭或空置 | 同上，负端勿接地 |
| MUTE / 电位器 | 按模块：电位器旋到中间再测；MUTE 勿误拉高导致静音 | 先小音量再加大 |

#### 通电顺序与验收

1. 先接好喇叭，再上 PAM8610 的 12V，再给 ESP32 USB/电池上电。  
2. 烧录现有 `make audio` 或主固件，播 TTS / 提示音。  
3. 从 PAM8610 电位器最小音量慢慢加大。

**验收**：

- [ ] DAC 模块 LED（若有）正常，无烫手异味  
- [ ] 有声音；大音量破音先降电位器，再查 12V 是否够流  
- [ ] ESP32 未因误接 12V 而损坏  

#### 安全红线

1. **12V 绝不能接到 ESP32 任意引脚或 5V 轨。**  
2. **喇叭负端（L-/R-）不要接到系统地。**  
3. 先共地、再送模拟信号，避免浮地打火。  
4. 现有 4Ω/3W 小喇叭功率远小于 PAM8610 标称，音量开太大会烧纸盆——对话够用即可。

#### 固件与本仓库的关系

- **默认路径仍是 MAX98357**；PAM8610 **不是**官方支持接法。  
- 按上文用 PCM5102A 时，多数情况**不用改代码**（仍用 GPIO14/26/27、16kHz）。  
- 若改用 ESP32 片内 DAC（GPIO25/26）：与本项目麦克风 SCK（25）、原功放 BCLK（26）**冲突**，需要改引脚与播放路径——**不推荐**，本文不提供该方案接线。

#### 和「继续用 MAX98357」怎么选

| 你的目标 | 建议 |
|----------|------|
| 降噪、说清楚话 | L1～L5，或换带滤波的 MAX98357（§8.1） |
| 只要更大一点 | 独立 5V + 更大喇叭/腔体，仍用 MAX98357 |
| 有 12V 电源、要很响 | 再上 PCM5102A + PAM8610（本节） |

### 8.3 怎么选

```
先做完 L1～L5？
  ├─ 听感 OK → 不必换模块
  ├─ 仍有嘶嘶 → 换「带 LC/滤波」的 MAX98357 板（§8.1）
  ├─ 想更大声、只有 5V → 独立 5V + 喇叭/腔体，别上 PAM8610
  └─ 有 12V、接受加 DAC → PCM5102A + PAM8610（§8.2）
```
