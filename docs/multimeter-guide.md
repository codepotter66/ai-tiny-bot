### 1.2 插孔说明

| 插孔 | 名称 | 用途 | 颜色 |
|------|------|------|------|
| **COM** | 地/负极 | 黑表笔固定插孔 | 黑色 |
| **VΩmA** | 电压/电阻/小电流 | 测电压、电阻、小电流（≤200mA）| 红色 |
| **10A** | 大电流 | 测大电流（200mA-10A）| 红色 |

**黑表笔**：始终插 **COM** 孔

**红表笔**：测电压/电阻/小电流 → **VΩmA**；测大电流（>200mA）→ **10A**

```

│  A C  D    │  ← AC=交流，DC=直流，D=直流
└─────────────┘
```

### 1.4 旋钮档位速查

| 你要测什么 | 旋钮转到 | 红表笔插哪 | 读数单位 |
|-----------|---------|-----------|---------|
| ESP32 3.3V 引脚电压 | **DCV 20V** | VΩmA | V（伏特）|
| ESP32 5V 引脚电压 | **DCV 20V** | VΩmA | V |
| TP4056 充电输出电压 | **DCV 20V** | VΩmA | V |
| 电池电压 | **DCV 20V** | VΩmA | V |
| 杜邦线/焊点是否接通 | **BEEP（二极管档）**| VΩmA | 有蜂鸣声=通 |

| 电阻值 | **Ω 对应档位** | VΩmA | Ω / kΩ / MΩ |

## 2. TinyPal 项目实战教程

### 2.1 测 ESP32 开发板电压（必做检查）

**场景**：接好线后，ESP32 不工作，先测电源。

**操作步骤**：

```
步骤 1：黑表笔插 COM，红表笔插 VΩmA

步骤 2：旋钮转到 DCV 20V（重要！电压档选比预期值大的档位）

步骤 3：红表笔接触 ESP32 的 3.3V 引脚
         黑表笔接触 GND 引脚

步骤 4：看屏幕读数
```

**预期结果**：
- 正常：显示 **3.28V - 3.36V**（正常范围）
- 偏低（<3.0V）：可能是供电不足，检查 USB 供电或电池
- 显示 0 或 0.00：说明没有供电，检查 USB 线 / 电池 / 接线
- 显示负数（如 -3.3）：表笔极性反了，红黑表笔换过来

**同样方法测 5V 引脚**：
- 旋钮转到 **DCV 20V**
- 红笔接 5V 引脚，黑笔接 GND
- 预期：**4.8V - 5.2V**

### 2.2 测 TP4056 充电输出（检查电池供电）

**场景**：电池供电时 ESP32 不工作，测充电板输出。

```
步骤 1：旋钮转到 DCV 20V

步骤 2：红笔接 TP4056 的 OUT+（或直接接 ESP32 的 VIN）
         黑笔接 TP4056 的 OUT-

步骤 3：看读数
```

**预期结果**：
- 插着 USB 充电：显示 **4.8V - 5.2V**（充电中或充满）
- 拔掉 USB，靠电池供电：显示 **3.7V - 4.2V**（满电 4.2V，放电后 3.7V）
- 显示 0：TP4056 OUT 没有输出，检查电池是否连接、TP4056 是否损坏

### 2.3 测电池电压（检查电池电量）

```
步骤 1：旋钮转到 DCV 20V

步骤 2：红笔接电池正极（红线），黑笔接电池负极（黑线）

步骤 3：看读数
```

**预期结果**：
- 充满电：4.0V - 4.2V
- 正常使用：3.7V - 4.0V
- 需要充电：<3.7V（低于 3.0V 过放保护会切断）

### 2.4 通断测试：检查杜邦线是否断了（最常用）

**场景**：接线后不工作，用蜂鸣档快速排查哪根线断了。

```
步骤 1：旋钮转到 BEEP（二极管档）

步骤 2：红笔和黑笔分别接触杜邦线的两端

步骤 3：听蜂鸣声
```

**结果判断**：
- **有蜂鸣声 + 显示较小数值（0-50）**：导线是通的 ✅
- **没有蜂鸣声 + 显示 1**（或 OL）：导线断了 ❌，换一根杜邦线
- **没有蜂鸣声 + 显示 0**：两根表笔碰在一起了（正常）

### 2.5 检查 MAX98357 功放是否有输入

**场景**：喇叭没声音，测功放模块是否正常通电。

```
步骤 1：旋钮转到 DCV 20V

步骤 2：红笔接 MAX98357 的 VIN 引脚
         黑笔接 MAX98357 的 GND 引脚

步骤 3：看读数
```

**预期结果**：显示 **4.8V - 5.2V**（功放需要 5V 才能工作，3.3V 声音会很小）

```
步骤 4：测 GND 确认
         红笔接 MAX98357 的 GND
         黑笔接 ESP32 的 GND（共地）
         应该显示 ~0V 或很小数值（<0.1V）
```

### 2.6 检查 OLED 屏幕供电

```
步骤 1：旋钮转到 DCV 20V

步骤 2：红笔接 OLED 的 VCC，黑笔接 OLED 的 GND

步骤 3：看读数
```

**预期**：显示 **3.3V** 左右。如果显示 0，检查接线；如果电压很低，检查 ESP32 3.3V 引脚负载能力。

## 3. 安全注意事项（完整版）

> 这是最重要的章节。万用表本身不贵（¥18），但用错一次烧掉的可能是价值 ¥100+ 的 ESP32、MAX98357 等模块。请务必读完。

### 3.1 损坏万用表本身的禁忌

这些操作会直接损坏你的万用表：

#### ⚠️ 测电压时红表笔插错孔

| 错误操作 | 后果 | 修复成本 |
|---------|------|---------|
| 红笔插 10A 孔，测电压 | 短路，10A 档位内部没有保险丝，会烧内部电路 | 万用表报废（¥18）|
| 红笔插 10A 孔，测电压且接触了高电压 | 更严重，可能烧焦 | 万用表报废 |

**正确做法**：只要测电压，红笔必须插 **VΩmA** 孔。

#### ⚠️ 在带电时切换档位

有些万用表切换档位的瞬间会产生瞬时过载，损坏内部。

**正确做法**：换档之前，先把表笔从电路上移开，或先关闭电源。

#### ⚠️ 测电流的方法错误

**测电流和测电压的操作完全不同：**

```
测电压（并联）：
  黑笔 COM，红笔 VΩmA
  表笔直接点在电路的两个点上
  → 安全，放心测

测电流（串联）：
  黑笔 COM，红笔 10A（>200mA）或 VΩmA（≤200mA）
  必须把电表串联进电路（断开一根线，把表笔串进去）
  → 操作复杂，且插错孔会短路
```

**对 TinyPal 的建议**：不要测电流。用测电压 + 通断足够排查所有问题。

#### ⚠️ 旋钮在电流档时去碰电路

如果旋钮停在 DCA 或 ACA 档，而红笔插在 VΩmA 或 10A孔，一旦表笔碰到有电压的地方，瞬间短路。

**养成习惯**：每次测完电压后，把旋钮转到 DCV 20V 或 OFF 档。

---

### 3.2 损坏电路元件的禁忌

这些操作会损坏 TinyPal 的模块（ESP32、MAX98357、OLED等）：

#### ⚠️ 测电压时表笔短路了两个引脚

这是最常见的失误。比如测 3.3V 的时候，表笔不小心同时碰了 3.3V 和 GND，引脚间形成短路。

**后果**：
- 瞬间拉低供电电压，导致 ESP32 复位重启
- 如果 ESP32 的某个 GPIO 被短路到 GND 或 VCC，可能烧毁该引脚
- 如果 MAX98357 的输入输出引脚被短路，可能损坏功放芯片

**正确做法**：
- 表笔每次只接触**一个**测试点
- 测 GND 时，黑笔先固定在 GND 上，只移动红笔去碰测试点
- 使用细尖的表笔头，而不是粗钝的

#### ⚠️ 用 Ω 档测带电的电路

测电阻时，万用表内部会向被测元件输出一个小电流来测量。如果电路带电，这个电流会干扰测量值，更危险的是：外部电压可能倒灌进万用表，损坏万用表或电路。

**正确做法**：
- 测电阻前**先断电**（拔掉 USB / 断开电池）
- 把被测元件**至少断开一端**（避免其他元件并联影响读数）
- 测完再通电

#### ⚠️ 用 Ω 档测带电容的电路

电容在断电后仍然存有电荷，测量时放电会损坏万用表。

**正确做法**：测电阻前，先等几秒让电容放电，或者在测试前用一个电阻把电容两脚短接放电。

#### ⚠️ 把 MAX98357 功放的 GAIN 脚接到错误电压

MAX98357 的 GAIN 脚用来设置功放增益。不要把它接到非接地的高电压上，否则可能损坏功放芯片。GAIN 脚悬空 = 默认 9dB，这是安全的。

#### ⚠️ ESP32 GPIO 引脚过载

ESP32 的 GPIO 最大只能承受 **3.3V**。如果你用 DCV 20V 档去测一个意外接到 5V 的 3.3V 引脚，没事。但如果把表笔不小心放到 5V 引脚上测，而红笔在 VΩmA 上，没问题。

**真正危险的是**：用万用表测电流档时，不小心把表笔接到有电压的地方。

### 3.3 万用表自保机制

MAS836L 有以下保护设计，但保护有限：

| 保护机制 | 保护范围 | 超出范围的损坏 |
|---------|---------|-------------|
| VΩmA 插孔有 **保险丝**（通常 200mA-500mA）| 测电压时短路 → 烧保险丝 | 换保险丝（¥1-2）|
| 10A 插孔 **无保险丝** | 大电流通过保护性熔断 | 万用表内部损坏 |
| 二极管/TVS 保护 | 瞬态高压冲击 | 只防瞬态，防不住持续高压 |

**关键结论**：VΩmA 孔烧了保险丝还能修；10A 孔烧了就基本报废。所以红笔插 10A 孔时**绝对不能测电压**。

---

### 3.4 正确操作规范（安全清单）

每次用万用表前，按这个清单过一遍：

```
□ 确认旋钮在哪个档位（电压/通断/电阻）
□ 确认红表笔插在哪个孔（VΩmA / 10A）
□ 测电压时，红笔只能在 VΩmA
□ 测完电压，把旋钮转到 DCV 20V 或 OFF
□ 不确定电压范围时，从 DCV 1000V 开始往下试
□ 表笔接触测试点时，两支笔不要碰在一起
□ 不要在带电时切换档位
□ 不要在带电时测电阻
□ 测电流不熟练，就不要测电流
□ 测 220V 插座——绝对不可以
```

### 3.5 意外发生后的处理

| 意外 | 现象 | 处理方法 |
|------|------|---------|
| 万用表不亮了 | 没反应 | 换万用表里的 9V 电池试试 |
| 万用表 VΩmA 档没读数 | 测什么都不显示 | 保险丝烧了，开壳换同规格保险丝（200mA-500mA 玻璃管保险丝）|
| 万用表显示 "1" 或 "OL" 在任何档 | 可能是万用表损坏 | 换一个 |
| ESP32 不亮了（测完电压后）| 可能 GPIO 过载损坏 | 换一块 ESP32 |
| MAX98357 发热发烫 | 可能内部短路 | 断电，检查接线，换一块 MAX98357 |

### 3.6 TinyPal 项目的安全边界

以下是你在 TinyPal 项目中会遇到的所有电压环境，全部在万用表的**安全范围内**：

| 测试点 | 预期电压 | 用什么档位 |
|--------|:-------:|---------|
| ESP32 USB 5V | 4.8V-5.2V | DCV 20V ✅ |
| ESP32 3.3V 引脚 | 3.28V-3.36V | DCV 20V ✅ |
| TP4056 OUT | 3.7V-5.2V | DCV 20V ✅ |
| 电池正负极 | 3.7V-4.2V | DCV 20V ✅ |
| MAX98357 VIN | 4.8V-5.2V | DCV 20V ✅ |
| OLED VCC | 3.3V | DCV 20V ✅ |
| MS4030 VCC | 3.3V | DCV 20V ✅ |
| **220V 插座** | **220V** | **绝对不要测 ❌** |

**结论**：TinyPal 项目所有电压都在 3.3V-5.2V 范围内，DCV 20V 档足够应对所有场景。只要旋钮在 DCV 20V 档，插错孔也不会产生灾难性后果（VΩmA 孔有保险丝保护）。

### 3.7 测电阻的正确方法

```
步骤 1：把万用表旋钮转到 Ω 档（先选 Ω 200 试试）

步骤 2：把被测元件从电路上断开（至少断开一端）
         例如：要测一根杜邦线，就把它从板子上拔下来

步骤 3：红笔插 VΩmA，黑笔插 COM

步骤 4：表笔接触被测元件两端

步骤 5：读数
         - 显示具体数值（如 0.2）= 正常，该元件有电阻
         - 显示 1 或 OL = 断路（无限大电阻）
         - 显示 0 = 短路
```

**为什么断开**：电路板上所有元件都连在一起，万用表测到的不是单个元件的电阻，而是整个回路的等效电阻，数值不准确。

---

### 3.8 正确测电流的方法（知道就行，不需要做）

**TinyPal 项目中几乎不需要测电流**，了解原理即可：

测电流需要把万用表**串联**进电路，意味着要先断开一根线，把表笔接进去：

```
错误方式（并联）：
  表笔直接点在电路两个点上
  → 这是测电压，不是测电流
  → 如果表笔插在 10A 孔，会短路

正确方式（串联）：
  断开一根线
  黑笔接 COM，红笔接 10A（测大电流）或 VΩmA（测小电流）
  把万用表串进电路：断开的那根线 → 红笔 → 黑笔 → 电路
  → 这是真正的测电流
```

**什么时候需要测电流**：
- MAX98357 功放最大输出电流约 2-3A，但 TinyPal 用的 3W 喇叭只需要约 0.5A，不需要测
- ESP32 工作电流 80-240mA，用 USB 供电表或电池续航时间就能估算，不需要测

## 4. 故障排查流程图

遇到问题时的排查顺序：

```
问题：ESP32 不工作 / 不亮灯
│
├── 量 1：测 ESP32 USB 口 5V 引脚
│         DCV 20V，红笔接 USB 5V，黑笔接 GND
│         │
│         ├── 读数 = 0
│         │    → USB 线坏了 或 USB 口没电
│         │    → 换一根 USB 线测试
│         │
│         └── 读数 = 4.8V-5.2V ✅
│              ↓
│         量 2：测 ESP32 3.3V 引脚
│              │
│              ├── 读数 < 3.0V
│              │    → ESP32 芯片可能坏了
│              │    → 或 3.3V LDO 过热
│              │
│              └── 读数 = 3.28V-3.36V ✅
│                   → ESP32 供电正常
│                   → 问题在固件或接线
│
问题：喇叭没声音
│
├── 量 1：测 MAX98357 VIN 引脚电压
│         DCV 20V，红笔 VIN，黑笔 GND
│         │
│         ├── 读数 < 4.5V ❌
│         │    → 检查 USB 供电或电池
│         │
│         └── 读数 = 4.8V-5.2V ✅
│              ↓
│         量 2：通断测试 MAX98357 GND 和 ESP32 GND
│              BEEP 档
│              │
│              ├── 没有蜂鸣 ❌
│              │    → GND 没有共地
│              │
│              └── 有蜂鸣 ✅
│                   → MAX98357 供电正常
│                   → 问题在 I2S 信号线或喇叭本身
│
问题：OLED 屏幕不亮
│
├── 量：测 OLED VCC 引脚电压
│      DCV 20V，红笔 VCC，黑笔 GND
│      │
│      ├── 读数 = 0 ❌
│      │    → OLED 没通电，检查接线
│      │
│      └── 读数 = 3.3V ✅
│           → OLED 供电正常
│           → 问题在 I2C 信号线（SDA/SCL）
```

## 6. 其他实用技巧

### 6.1 自动档 vs 手动档

MAS836L 是**手动档**万用表——你需要先估计数值，选一个大于但最接近的档位。

**量程选择原则**：选一个比预期值大，但不要太高的档位。

```
例：测 3.3V
  ❌ DCV 200V（太大，精度不够）
  ✅ DCV 20V（最合适）
  ❌ DCV 2V（太小，撞档显示 1）

例：测 5V
  ❌ DCV 200V（太大）
  ✅ DCV 20V（合适）
  ❌ DCV 2V（太小）

例：测 3.7V 电池
  ✅ DCV 20V（合适）
  ✅ DCV 2000mV（更精确，显示 3700mV）
```

### 6.2 读数 "1" 或 "OL" 的含义

- 数字万用表显示 **"1"** 或 **"OL"**（Over Load）：超过当前档位最大值，说明被测值比当前档位量程大
- 处理方法：把旋钮换到更大的档位

```
例：在 Ω 200 档测一根通的杜邦线，显示 1
    → 说明电阻小于 0.1Ω，小于 200Ω 量程能显示的最小值
    → 正常，说明线是通的
```

### 6.3 如何保存电池

MAS836L 使用 **9V 电池**（给万用表自己供电）。

- 如果长时间不用，把旋钮转到 **OFF** 档
- 如果屏幕显示变暗或出现 "LOBAT"，换 9V 电池（万用表电池，不是 TinyPal 的电池）
- 换电池：打开后盖，通常用十字螺丝刀拧开

### 6.4 屏幕显示负号

如果读数前面有一个减号 "-"，说明极性反了。交换红黑表笔即可。
