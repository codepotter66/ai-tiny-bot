# 到货检查指南 — 用万用表验证每个配件

> 万用表: MAS836L | 检查顺序: 从独立配件到组装

---

## 第 0 步：万用表自检（拿到后第一步）

这一步在检查任何配件之前做，验证万用表本身是好的：

```
1. 黑表笔 ──→ 插 COM 孔

2. 红表笔 ──→ 插 VΩmA 孔

3. 旋钮 ───→ 转到 BEEP（二极管档）

4. 红表笔和黑表笔的金属尖端直接相碰

5. 听蜂鸣声
```

**预期结果**：
- 有蜂鸣声 ✅ → 万用表电池正常，通断档正常，可以开始使用
- 没有蜂鸣 ❌ → 可能是万用表内部 9V 电池没电了，需要换电池

**通过 → 万用表本身没问题 ✅，开始检查配件**

---

## 第 1 步：检查 ESP32 开发板（最重要）

### 1.1 外观检查

- 看开发板有没有明显裂痕、烧焦痕迹
- 确认 USB 口、CH340 芯片、ESP32 芯片都在位
- 确认排针整齐，没有歪斜（如果板子自带排针的话）

### 1.2 测 USB 5V 输出

**不需要接任何东西，直接测**

```
旋钮: DCV 20V

红表笔 ──→ 摸 ESP32 开发板的 USB 口的金属内壳（5V 触点）
黑表笔 ──→ 摸 USB 口的金属外壳（GND）

读数：
  4.8V - 5.2V ✅ 板子 USB 口正常
  0V ❌ USB 口有问题
```

### 1.3 测 3.3V 输出（不用接任何东西）

USB 口旁边有一个 3.3V 引脚（或标 "3V3"）：

```
旋钮: DCV 20V

红表笔 ──→ 3.3V 引脚
黑表笔 ──→ GND 引脚（旁边标 GND 的针脚）

读数：
  3.28V - 3.36V ✅ 3.3V LDO 正常
  <3.0V 或 >3.6V ❌ 有问题
  显示 0 ❌ 检查 GND 位置是否找对
```

**找 GND 引脚的方法**：USB 口旁边标了 GND 的针脚，通常有好几个 GND，随便选一个。

### 1.4 检查 3.3V 和 GND 之间没有短路

```
旋钮: BEEP（二极管档）

红表笔 ──→ 3.3V 引脚
黑表笔 ──→ GND 引脚

读数：
  有蜂鸣声 + 显示 0.x ❌ 3.3V 和 GND 短路了，板子有问题
  没有蜂鸣 + 显示 1 ❌ 正常，没有短路
```

**通过 → ESP32 开发板没问题 ✅**

---

## 第 2 步：检查 0.96" OLED 屏幕

### 2.1 外观检查

- 4 针排针是否整齐、焊锡饱满
- 屏幕有没有碎角（OLED 屏很脆）
- 排针上有没有异物

### 2.2 测屏幕供电是否正常

**屏幕不接 ESP32，单独测**。4 针分别是 VCC / GND / SDA / SCL，但 VCC 和 GND 很好认（通常是第 1 和第 2 针）：

```
旋钮: DCV 20V

红表笔 ──→ 屏幕的 VCC 针（最边上那个，通常是第1针）
黑表笔 ──→ 屏幕的 GND 针（第2针）

读数：
  显示 0V ✅（屏幕还没接电，没有短路）
  显示 >0.5V ❌ 屏幕可能内部短路
```

### 2.3 检查屏幕 VCC 和 GND 之间没有短路

```
旋钮: BEEP

红表笔 ──→ VCC 针
黑表笔 ──→ GND 针

读数：
  有蜂鸣声 ❌ 屏幕内部短路，不要接 ESP32
  没有蜂鸣 ✅ 正常
```

**通过 → OLED 屏幕没问题 ✅**

---

## 第 3 步：检查 MAX98357 音频放大器

### 3.1 外观检查

- 芯片在不在位（正方形芯片，引脚很多）
- 芯片有没有烧焦、发黑
- 排针是否整齐

### 3.2 检查 VCC 和 GND 没有短路

```
旋钮: BEEP

红表笔 ──→ 模块的 VIN（或标 VCC/5V 的针）
黑表笔 ──→ 模块的 GND 针

读数：
  有蜂鸣 ❌ 功放模块内部短路，不要通电
  没有蜂鸣 ✅ 正常
```

### 3.3 检查 GAIN 脚和 SD 脚状态

GAIN 脚悬空 = 默认 9dB（正常）。SD 脚接 VIN 才使能。

```
旋钮: DCV 20V

红表笔 ──→ GAIN 针
黑表笔 ──→ GND 针

读数：
  0V 或 <0.5V ✅ 悬空状态（正常）
  有电压 ✅ 也正常，说明内部有上拉电阻
```

**通过 → MAX98357 没问题 ✅**

---

## 第 4 步：检查 MS4030 麦克风

### 4.1 外观检查

- 麦头（黑色方块）有没有歪斜
- 排针是否整齐
- 麦头周围有没有裂痕

### 4.2 检查 VCC 和 GND 没有短路

```
旋钮: BEEP

红表笔 ──→ 模块的 VCC 针
黑表笔 ──→ 模块的 GND 针

读数：
  有蜂鸣 ❌ 麦克风内部短路
  没有蜂鸣 ✅ 正常
```

**通过 → 麦克风没问题 ✅**

---

## 第 5 步：检查 TP4056 充电模块

### 5.1 外观检查

- USB-C 口有没有歪斜
- 芯片和周围的元件是否完整
- 两排针脚是否整齐

### 5.2 检查 OUT+ 和 OUT- 没有短路

```
旋钮: BEEP

红表笔 ──→ OUT+（或标 B+）
黑表笔 ──→ OUT-（或标 B-）

读数：
  有蜂鸣 ❌ 短路，不要接电池
  没有蜂鸣 ✅ 正常
```

### 5.3 测 USB-C 供电时 OUT 有无输出

**注意：这一步要在接电池之前做，防止电池接反而烧**

```
旋钮: DCV 20V

找 TP4056 上标了 USB 或 USB-C 的口，用手机充电线插上去

红表笔 ──→ OUT+ 针
黑表笔 ──→ OUT- 针

读数：
  4.8V - 5.2V ✅ 充电模块正常，可以接电池
  0V ❌ 充电模块有问题，不要接电池
```

**通过 → TP4056 没问题 ✅**

---

## 第 6 步：检查锂电池（先不接电路）

### 6.1 外观检查

- 外壳有没有膨胀（胀了 = 坏了）
- 插头线有没有裸露
- 正负极有没有标识

### 6.2 测电池电压

```
旋钮: DCV 20V

红表笔 ──→ 电池红线（正极）
黑表笔 ──→ 电池黑线（负极）

读数：
  3.7V - 4.2V ✅ 电池有电，状态正常
  3.5V - 3.7V ✅ 有点低，但能用，充一下更好
  <3.3V ❌ 电池过放，可能已经损坏
  0V ❌ 电池坏了，或正负极接反了
```

---

## 第 7 步：检查喇叭

喇叭不需要万用表测，用手摸一下纸盆（薄膜部分）：

- 按压纸盆，有弹性，不卡 ✅
- 纸盆没有裂痕 ✅
- 接线有没有脱焊 ✅

没有万用表操作，但顺手检查一下。

## 额外提示

- 每测完一个配件，把万用表旋钮转回 **DCV 20V**，养成习惯
- 测电压时，表笔只接触**一个**针脚，不要同时碰两个引脚
- 如果你不确定哪个针是 GND，先用 **BEEP** 档找到导通的两个点，那通常是 GND 和 VCC
