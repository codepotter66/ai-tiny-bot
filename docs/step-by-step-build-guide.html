如何接电源（先看这里）

整机只有一个主供电入口：ESP32 开发板。 OLED / 麦克风 / 功放都从 ESP32 的 3.3V 或 5V 取电，不需要再单独接墙插。

方式 A：USB 供电开发推荐

  1. 用能传数据的 USB 线，把 ESP32 接到电脑（或 5V USB 充电器）
  2. 板上电源灯亮 → 已供电；同一根线也可烧录固件
  3. 桌面联调、第 3–6 步都可以先只用这一种，不必接电池

方式 B：锂电池 + TP4056便携成品

  1. 锂电池红/黑 → TP4056 的 B+ / B-（充电输入）
  2. TP4056 的 OUT+ / OUT- → ESP32 的 VIN / GND
  3. 给电池充电：充电器插 TP4056 的 USB-C（不是插 ESP32）
  4. 细节与万用表验证见下方 第 1 步、第 2 步
电源关系（记这一张就够） [电脑 / 充电器 USB] ──→ ESP32 USB口 ──┐ ├─→ ESP32 内部稳压 [锂电池] → TP4056 → ESP32 VIN/GND ────┘ │ ├─→ 3.3V → OLED、麦克风(MS4030) └─→ 5V → 功放(MAX98357)、喇叭驱动
注意： ① 极性千万别反：电池红→B+，黑→B-；OUT+→VIN，OUT-→GND。 ② 开发时若已用 USB 供电，可先不接 VIN；电池与 USB 同时接时，优先用质量可靠的 TP4056 模块，并确认 OUT 没有短路。 ③ 麦克风吃 3.3V，功放吃 5V，不要接反。

电池 + TP4056 供电测试

接线

锂电池（3.7V）              TP4056 充电模块
┌──────────────┐         ┌──────────────────┐
│  红线 = 正极  │ ──────→ │  B+ / IN+        │  ← 电池进来充电
│  黑线 = 负极  │ ──────→ │  B- / IN-        │
└──────────────┘         │  USB-C           │  ← 插充电器给电池充
                         │  OUT+ / OUT-     │  ← 本步先不接 ESP32
                         └──────────────────┘

接线顺序（断电、先不插充电器）：
1. 电池红线 → TP4056 B+（有的板标 IN+）
2. 电池黑线 → TP4056 B-（有的板标 IN-）
3. 确认没接反后再测电压（下一步）

说明：B+/B- 是「接电池」；OUT+/OUT- 是「输出给 ESP32」。
不要把电池直接接到 ESP32 的 3.3V。

万用表检查（接好后测）

步骤 1：万用表自检
  BEEP 档 → 红笔黑笔相碰 → 有蜂鸣 ✅

步骤 2：测充电模块 OUT 输出
  DCV 20V
  红笔 → TP4056 OUT+（标 B+ 或 OUT+）
  黑笔 → TP4056 OUT-（标 B- 或 OUT-）

  读数：
    4.8V - 5.2V ✅ → 充电模块正常
    0V ❌ → 重新检查接线

步骤 3：确认正负极没有接反（没蜂鸣说明没短路）
  BEEP 档
  红笔 → TP4056 OUT+
  黑笔 → TP4056 OUT-

  没蜂鸣 ✅（没有短路）

通过标准

  • 万用表测 OUT+ / OUT- 显示 4.8V-5.2V
  • OUT+ / OUT- 之间没有蜂鸣（没有短路）

电池 → ESP32 供电

若你暂时只用电脑 USB 给 ESP32 供电（方式 A），可跳过本步，直接做第 3 步烧录； 做便携成品时再回来接电池。

接线

TP4056（电池已接好）          ESP32 DevKit
┌──────────────────┐         ┌──────────────────┐
│  OUT+            │ ──────→ │  VIN（或标 5V）   │  ← 板载稳压输入
│  OUT-            │ ──────→ │  GND（任意一个）  │
│  B+ / B-         │ ── 已接电池               │
│  USB-C           │ ── 需要充电时再插         │
└──────────────────┘         └──────────────────┘

只需 2 根杜邦线：
  OUT+ → VIN
  OUT- → GND

不要接到 3.3V 针脚（电压过高会损坏芯片）。

万用表检查

步骤 1：确认 ESP32 3.3V 正常
  DCV 20V
  红笔 → ESP32 的 3.3V 引脚
  黑笔 → ESP32 的 GND 引脚

  读数：
    3.28V - 3.36V ✅ → ESP32 供电正常
    <3.0V ❌ → 检查 TP4056 OUT 是否接对 VIN
    0V ❌ → 检查 GND 位置，或 TP4056 OUT 有没有电

步骤 2：确认 3.3V 和 GND 没有短路
  BEEP 档
  红笔 → 3.3V 引脚
  黑笔 → GND 引脚

  没蜂鸣 ✅（3.3V 和 GND 之间无短路）

通过标准

  • 3.3V 引脚显示 3.28V-3.36V
  • 3.3V / GND 之间没有短路

写入测试代码

打开 src/main.cpp，删除全部内容，替换为：

#include <Arduino.h>

// ESP32 内置 LED 通常在 GPIO2
#define LED_PIN 2

void setup() {
    pinMode(LED_PIN, OUTPUT);
    Serial.begin(115200);
    Serial.println("Blink test started");
}

void loop() {
    digitalWrite(LED_PIN, HIGH);
    Serial.println("LED ON");
    delay(1000);
    digitalWrite(LED_PIN, LOW);
    Serial.println("LED OFF");
    delay(1000);
}

写入屏幕测试代码

在 PlatformIO 中新建项目 tinypal-oled，或在现有项目中新建文件 src/oled_test.cpp：

#include <Arduino.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SCREEN_WIDTH  128
#define SCREEN_HEIGHT 64
#define OLED_RESET    -1
#define OLED_ADDR    0x3C

Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, OLED_RESET);

void setup() {
    Serial.begin(115200);

    Wire.begin(21, 22);  // SDA=GPIO21, SCL=GPIO22

    if (!display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDR)) {
        Serial.println("OLED init FAILED!");
        while (true);
    }

    Serial.println("OLED init OK!");
    display.clearDisplay();
    display.setTextColor(SSD1306_WHITE);
    display.setTextSize(2);
    display.setCursor(20, 25);
    display.println("TinyPal");
    display.setTextSize(1);
    display.setCursor(30, 50);
    display.println("Hello World!");
    display.display();
}

void loop() {
    // 屏幕静态显示，不需要 loop 刷新
}

接线音频（麦克风 + 功放 + 喇叭）

接线 — MS4030 麦克风（常见 6 针）

常见模块焊针为：SD / VDD / GND / L/R / WS / SCK。 丝印 VDD 与文档里偶见的 VCC 是同一根电源正极，接到 ESP32 3.3V（不要接 5V）。 少数板子多一颗空脚 DC，不用接。

软件注意：MS4030（INMP441 兼容）输出 24-bit 数据落在 32-bit I2S 槽。 固件必须按 32-bit 读入再右移对齐成 16-bit PCM；若按 16-bit 直接读，回放会电音/杂乱。 实时回放测试时麦克风尽量远离喇叭，避免啸叫。 

MS4030 模块           ESP32
┌──────────────────┐
│  VDD  ──────────→│  3.3V   ← 电源正极（有的板丝印为 VCC）
│  GND  ──────────→│  GND    ← 电源负极 / 地
│  L/R  ──────────→│  GND    ← 声道选择：接地 = 左声道
│  SD   ──────────→│  GPIO32 ← I2S 数据输出（麦克风 → ESP32）
│  WS   ──────────→│  GPIO33 ← I2S 字选择 / 左右时钟（LRCLK）
│  SCK  ──────────→│  GPIO25 ← I2S 位时钟（BCLK）
└──────────────────┘

MS4030 各焊针说明

焊针 全称 / 含义 作用 本项目接法
VDD Voltage Drain / 电源正极（等同 VCC） 给麦克风芯片供电，工作电压约 1.8–3.3V ESP32 3.3V
GND Ground / 地 电源回路与信号参考地，必须与 ESP32 共地 ESP32 GND
L/R Left / Right Select / 声道选择 决定麦克风数据走 I2S 左声道还是右声道；接 GND=左，接 VDD=右 GND（选左声道，与固件一致）
SD Serial Data / 串行数据 麦克风把采集到的数字音频通过此脚送给 ESP32（I2S DATA / DOUT） GPIO32
WS Word Select / 字选择（也称 LRCLK） 标识当前采样属于左还是右声道的帧同步时钟，由 ESP32 提供 GPIO33
SCK Serial Clock / 串行时钟（也称 BCLK） I2S 位时钟，决定每一位数据何时采样，由 ESP32 提供 GPIO25
DC（可选） 部分 7 针板才有 本方案不用，悬空即可 空（不接）

接线 — MAX98357 功放

常见模块丝印为 LRC（不是 LRCLK）——二者是同一根脚：Left/Right Clock，左右声道帧时钟。 接到 ESP32 GPIO27 即可。 

MAX98357 模块        ESP32 / 喇叭
┌──────────────────┐
│  VIN  ──────────→│  5V     ← 功放电源（注意不是 3.3V）
│  GND  ──────────→│  GND    ← 地
│  DIN  ──────────→│  GPIO14 ← I2S 数据输入（ESP32 → 功放）
│  BCLK ──────────→│  GPIO26 ← I2S 位时钟
│  LRC  ──────────→│  GPIO27 ← I2S 字选择 / 左右时钟（有的板丝印为 LRCLK）
│  GAIN ──────────→│  悬空   ← 增益脚，悬空默认约 9dB
│  SD   ──────────→│  5V     ← Shutdown 使能：接高电平才工作
│  SPK+ ──────────→│  喇叭红线
│  SPK- ──────────→│  喇叭黑线
└──────────────────┘

MAX98357 各焊针说明

焊针 全称 / 含义 作用 本项目接法
VIN Voltage In / 电源输入 给功放芯片和喇叭驱动供电，电流需求比麦克风大 ESP32 5V（不要接 3.3V）
GND Ground / 地 电源与信号地，与 ESP32、喇叭共地 ESP32 GND
DIN Data In / 数据输入 接收 ESP32 发来的 I2S 数字音频数据 GPIO14
BCLK Bit Clock / 位时钟 I2S 位时钟，与麦克风侧的 SCK 同类，但功放走独立一组引脚 GPIO26
LRC Left/Right Clock / 左右时钟（等同 LRCLK） 帧同步，标识左右声道；与麦克风侧的 WS 同类 GPIO27
GAIN Gain / 增益选择 通过接法改变放大倍数；悬空约为 9dB 悬空（默认增益）
SD Shutdown / 关断控制 低电平关断、高电平使能；不接高电平则喇叭无声 接 5V（与 VIN 同电位）
SPK+ Speaker Positive / 喇叭正极 差分输出正极，接喇叭红线 喇叭红线
SPK- Speaker Negative / 喇叭负极 差分输出负极，接喇叭黑线 喇叭黑线

接线清单

  • MS4030：6 根线（VDD/GND/L/R/SD/WS/SCK）
  • MAX98357：信号与电源 5 根（VIN/GND/DIN/BCLK/LRC）+ SD 使能 1 根 + 喇叭 2 根

常见问题排查

问题 排查
没有声音 MAX98357 SD 脚有没有接 5V？GAIN 脚有没有悬空？喇叭接线正负极？
声音很小 VIN 是否在 5V？（不是 3.3V）3W 喇叭阻抗是否 4Ω？
麦克风录不到 VDD 是否接到 3.3V（不是 5V）？L/R 是否接地？SD/WS/SCK 是否插紧？
录到全是杂音 / 电音 固件须 32-bit 读 MS4030 再右移（MIC_PCM_SHIFT）；杜邦线勿超过 30cm；回放时麦远离喇叭防啸叫

通过标准

  • 喇叭能发出启动提示音
  • 对着麦克风说话，喇叭能实时回放（人声可辨、无明显电音）
  • OLED 显示音量条

启动云端服务 + seed 设备

在跑 tiny-bot-cloud-agent 的机器上执行。 seed 只是在云端数据库预登记设备（入场许可），不会让板子立刻在线； 板子上电后还会走 WiFi → /provision 拿 token → WebSocket。 固件 config.h 的设备 ID/配对码必须与 seed 一致。 未 seed 时 OLED 会一直 Reconnecting...（串口常见 device not found / 401）。 

cd tiny-bot-cloud-agent

./bin/tiny-bot-cloud-agent
